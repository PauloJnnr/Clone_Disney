Uma recriação visual e funcional da interface do Disney+, construída para demonstrar domínio em HTML, CSS/SASS, automação com Gulp e organização profissional de um projeto front-end.

O objetivo deste projeto é praticar a construção de interfaces modernas, estruturação limpa e escalável, e preparar terreno para evoluir o clone para algo realmente funcional (API, autenticação, busca dinâmica, etc).



🚀 Tecnologias Utilizadas

• HTML5
• CSS3 / SASS
• JavaScript (Vanilla)
• Gulp (build automation)
• Node.js + NPM
• Responsividade mobile-first
